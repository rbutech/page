HTML is intentionally supported because this is a static CMS. You can paste headings, paragraphs, tables, images, links, cards, etc.

Navigation behavior

The navigation is generated automatically from the page tree. Main links are all top-level pages. On a page with children, its children are shown in the left sidebar. A page can itself have children, so the same structure works for deeper levels.
