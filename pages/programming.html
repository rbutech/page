Introduction

Python is a programming language that allows us to give instructions to a computer. We can use it to automate repetitive work, develop websites and APIs, analyse data, build AI applications and test software.

In this lesson, you will set up Python on Windows and learn the building blocks needed to write useful programs.

Learning objective: By the end of this page, you should be able to run a Python program, store values in variables, convert data types, accept keyboard input, perform calculations and identify common errors.

Python code, interpreter and output

Python code

The instructions written by a programmer, such as print("Hello").

Python interpreter

The software that reads and executes Python instructions.

Program output

The result produced by the program, such as the text Hello.

Source file

A file such as hello.py that stores Python code.

What Is Python?

Python is a high-level, general-purpose programming language. Its syntax is designed to be readable, so beginners can focus on solving problems instead of learning complicated punctuation.

Readable

Interpreted

Cross-platform

Python is available on Windows, macOS and Linux.

Rich ecosystem

Libraries provide ready-made tools for web development, data, AI and testing.

Install Python on Windows

Install the official Python distribution on your Windows computer. You normally need to install Python only once for a given installation, though multiple versions can coexist.

Installation diagram

Python Installation Workflow
DownloadOfficial Python website
→
Run installerChoose options
→
InstallWait for completion
↓
Verify in Command Promptpython --version

Step-by-step instructions

  1. Open the official download page: Python downloads for Windows.
  2. Download a suitable stable Python 3 release for your Windows system.
  3. Open the downloaded installer.
  4. If the installer offers Add python.exe to PATH or Add Python to PATH, select it if you want to run Python using the python command from Command Prompt.
  5. Choose the standard installation option, or customize the installation if you have a specific requirement.
  6. Wait until the installer confirms that the installation is successful.
  7. Open a new Command Prompt and verify the installation in the next section.
Important: Installer screens can vary by Python version and installation method. If Python is already installed, check the existing version before installing another copy.

What does “Add Python to PATH” mean?

PATH is a Windows environment variable containing folders where Windows searches for executable programs when you enter a command.

How PATH helps Windows find Python
You typepython hello.py
→
Windows searches PATHLooks in configured folders
→
Python startsRuns your file
  • With PATH configured: You can usually type python directly in Command Prompt.
  • Without PATH configured: The Python installation may still exist, but Windows might not find it using that command.
  • Alternative: On many Windows installations, the Python launcher command py works even when python is not recognized.
06

Verify Installation

Command Prompt is a Windows tool that lets you enter commands. Use it to confirm that Python is installed and accessible.

Open Command Prompt

  1. Press Windows + R.
  2. Type cmd.
  3. Press Enter.

Check the Python version

Command Prompt
python --version
Example output — your version may differPython 3.13.7

You can also try the Windows Python launcher:

Command Prompt
py --version
Example outputPython 3.13.7

The version shown on your computer depends on the release you installed.

Open Python interactively

Command Prompt
python
Example interpreter prompt>>> print("Hello") Hello >>> 10 + 5 15 >>>

The >>> prompt indicates that Python is ready for an instruction. Enter one expression at a time. To leave the interactive interpreter, type exit() or press Ctrl+Z and then Enter on Windows.

If Python is not recognized: Try py --version. If that works, use py to run programs. Otherwise, check whether Python is installed, review the installer's PATH option, and reopen Command Prompt after making changes.

You can write Python in interactive mode or save it in a file ending in .py. A file is more useful when you want to save, reuse and share a program.

Remember: Python source code is what you write. The interpreter runs that code. The output is what you see after the instructions execute. The output is not the same thing as the source code.
08

Python Syntax

Syntax means the rules used to write valid instructions in a programming language.

Important rules

  • Text values normally appear inside single or double quotes.
  • Python is case-sensitive: name and Name are different variables.
  • Parentheses are used when calling functions, such as print().
  • Use a colon (:) after statements that begin an indented block, such as if and for.
  • Indentation matters. Python uses indentation to define code blocks.
  • Python generally uses a new line for each statement.

Example: a simple calculation

Python
print(10 + 5)
print("10 + 5")
Expected output15 10 + 5

Explanation: In the first statement, Python calculates the expression. In the second, the expression is inside quotation marks, so Python prints it as text.

Variables

A variable is a name that refers to a value. You can use it to store information and reuse that information later in your program.

Variable-to-value relationship

A Variable Refers to a Value

Example: creating variables

Purpose: Store a name, age and salary.

Python
name = "Ravi"
age = 25
salary = 3500.50

print(name)
print(age)
print(salary)
Expected outputRavi 25 3500.5

Explanation: The = symbol assigns a value to a variable. Python determines the type from the assigned value. The final output displays the values referenced by the variables.

Variable naming rules

  • Names can contain letters, digits and underscores.
  • A name cannot start with a digit.
  • Spaces are not allowed in variable names.
  • Names are case-sensitive.
  • Python keywords such as if, class and for cannot be used as ordinary variable names.
  • Prefer descriptive names such as total_price and student_name.

Valid names

student_name
age2
total_price

Invalid names

2age — starts with a digit
student name — contains a space
class — reserved keyword

Type Conversion

Type conversion changes a value from one type to another. Python provides functions such as int(), float() and str().

FunctionExampleResult
int()int("25")25
float()float("3.5")3.5
str()str(100)"100"
bool()bool(0)False

Example: convert a string to an integer

Python
number_text = "100"
number = int(number_text)

print(number)
print(number + 50)
print(type(number))
Expected output100 150 <class 'int'>

Explanation: Initially, number_text is a string. The int() function converts the numeric text to an integer, allowing arithmetic addition.

Common mistake: int("hello") raises a ValueError because "hello" is not a valid integer representation. Converting a floating-point value such as int(3.9) produces 3; it truncates the fractional part rather than rounding.

Input and Output

Input is information received by a program. Processing means performing calculations or making decisions. Output is the result presented to the user.

Input → Processing → Output
InputEnter two numbers
→
ProcessingAdd the numbers
→
OutputDisplay the total

Using input()

The input() function displays an optional prompt and waits for the user to enter text. It returns a string, even if the user enters digits.

Example: read user input

Python
name = input("Enter your name: ")
print("Hello,", name)
Example interactionEnter your name: Ravi Hello, Ravi

Explanation: Python waits for the user to enter a name. The returned string is stored in name and displayed using print().

Example: format output using an f-string

An f-string lets you place variable values or expressions inside curly braces.

Python
name = "Ravi"
age = 25
print(f"My name is {name} and I am {age} years old.")
Expected outputMy name is Ravi and I am 25 years old.

Explanation: The letter f before the opening quotation mark enables expression substitution. Python replaces {name} and {age} with their current values.

Example: read numbers and calculate

Python
first = int(input("Enter first number: "))
second = int(input("Enter second number: "))

total = first + second
print(f"Total = {total}")
Example interactionEnter first number: 10 Enter second number: 20 Total = 30

Explanation: Each call to input() returns a string. int() converts that string into an integer before addition.

Common mistake: input() returns strings. For example, "10" + "20" produces "1020", not 30. Convert the input to a number when you need arithmetic.

Comparison operators

Comparison operators compare two values and produce a Boolean result: True or False.

Python
age = 20

print(age > 18)
print(age == 20)
print(age != 25)
print(age < 18)
Expected outputTrue True True False

Logical operators

and is true when both conditions are true. or is true when at least one condition is true. not reverses a Boolean result.

Python
age = 25
has_id = True

print(age >= 18 and has_id)
print(age < 18 or has_id)
print(not has_id)
Expected outputTrue True False

Assignment operators

Python
score = 10
score += 5
print(score)

score -= 3
print(score)
Expected output15 12

Explanation: score += 5 updates the current value by adding five. It is equivalent to score = score + 5.

Remember: = assigns a value, while == checks whether two values are equal.

Comments and Indentation

Comments

A comment explains the code to a person reading it. Python ignores the part of a line that follows a comment marker outside a string.

Python
# Calculate the total price
price = 100
tax = 5
total = price + tax

print(total)  # Display the result
Expected output105

Indentation

Indentation means the spaces at the beginning of a line. Python uses indentation to identify the statements inside a block. Four spaces per indentation level is the common convention.

Indentation Defines a Code Block
age = 20

if age >= 18:
    print("Adult")
    print("Eligible")

print("Program finished")

Both indented print statements belong to the if block. The final statement is outside the block because it starts at the left margin.

Correct

if True:
    print("Hello")

Incorrect

if True:
print("Hello")

This causes an indentation error.
