01 • Start Here

What exactly is Python?

Python is a high-level, general-purpose programming language designed to make software easier for humans to read and write.

01

What is Python?

Python is a programming language. You write instructions using Python syntax and the Python interpreter reads and executes those instructions.

Simple idea: Python lets you describe what you want a computer to do using readable instructions.
Real-world application: Python is used to automate repetitive tasks, build websites, analyze data, create AI systems, test software and communicate with databases.
Common mistake: Python is not an operating system. It is a programming language and its interpreter is the software that executes Python code.
Practice: In your own words, explain what a programming language does.

04 • Installation

Install Python on Windows

Installing Python is the first practical step. The process is simple: download Python, install it, verify it and then create your project.

1

Download Python

Visit the official Python website and download the current Python 3 release for Windows.

2

Run the installer

Start the installer and follow the installation wizard. On Windows, pay attention to the option that adds Python to your PATH.

3

Configure PATH

Enabling the PATH option allows commands such as python to be recognized from a terminal.

4

Open a terminal

Open Windows Terminal, PowerShell or Command Prompt.

5

Verify Python

Ask Python for its version to confirm that the installation is available.

C:\Users\Student> python --version
Python 3.x.x

Installation Flow

Download Get Python installer.
→
Install Run the setup wizard.
→
PATH Make Python available in terminal.
→
Terminal Open a command shell.
→
Verify Check Python version.
→
First File Create hello.py.
→
Run Execute your program.

Problem: "python is not recognized"

Windows cannot find the Python command. Check that Python was installed correctly and that the installer added Python to PATH.

Problem: Wrong Python command

Some Windows installations use the py launcher. Try py --version to check whether it is available.

What is the interpreter?

The Python interpreter is the program that reads Python code and executes it. Your .py file contains instructions; the interpreter is the software that makes those instructions run.

05 • Your Workspace

VS Code or IDLE?

You can write Python with a full code editor such as VS Code or use IDLE, which is included with many Python installations.

VS Code

Visual Studio Code is a powerful general-purpose editor. With the Python extension, it provides syntax highlighting, debugging, code navigation and many developer conveniences.

Recommended for: learners who want to continue from beginner Python into professional development.

IDLE

IDLE is a lightweight Python development environment. It is useful for learning basic Python without configuring a larger editor.

Recommended for: beginners who want a simple Python-focused environment.

Write your first Python program

The traditional first Python program is a simple message printed to the terminal.

↓

↓
Interpreter Reads and executes code.
↓
Execution Instructions are performed.
↓
Terminal Result appears.
hello.py

Expected output

How does it work?

print() is a built-in Python function that sends text to the program's standard output, usually the terminal.

Real-world application: Output is how programs communicate information to users, logs, terminals, files and other systems.
Common mistake: Forgetting quotation marks around text: print(Hello) is not the same as print("Hello").
Practice: Change the program so that it prints your name.
07 • Syntax

Python syntax and indentation

Syntax describes the rules used to write valid Python code. Indentation is especially important because Python uses indentation to define blocks of code.

Comments

Comments are notes for humans. Python ignores text after a # when it is used as a comment.

comments.py 
# This is a comment
name = "Naveen"  # Store a name
Common mistake: Do not use comments as a substitute for understanding the code.

Indentation

Python uses indentation to indicate that statements belong to the same block.

indentation.py 
age = 20

if age >= 18:
    print("Adult")
Common mistake: Mixing inconsistent indentation can cause an IndentationError.
Good habit: Use consistent indentation. The standard style for Python code is commonly four spaces per indentation level.
08 • Variables

Variables and memory

A variable name is a name bound to a Python object. Thinking of a variable as a label pointing to an object is more accurate than thinking of it as a permanently allocated box.

age

19000

Expected output
Naveen
37
19000
Real-world application: Variables can represent customer names, prices, product quantities, account balances, configuration values and many other pieces of data.
Common mistake: Python variable names are case-sensitive. name and Name are different names.

Variable naming conventions

Style Example Recommendation
snake_case first_name Preferred for ordinary Python variables.
UPPER_CASE MAX_SIZE Commonly used for constants.
camelCase firstName Common elsewhere, but not normal Python style.
PascalCase StudentRecord Commonly used for classes.
09 • Data

Python data types

A data type describes what kind of object you are working with and what operations make sense for that object.

Python Data Types
int Whole numbers — 10, 37, -5 Use: counts, ages, quantities.
float Decimal numbers — 19.5 Use: measurements, prices.
str Text — "Python" Use: names, messages.
bool True or False Use: decisions and conditions.
NoneType Represents absence of a value. Example: None
list Ordered, mutable collection. Example: [10, 20, 30]
tuple Ordered, immutable collection. Example: (10, 20)
set Collection of unique elements. Example: {"red", "blue"}
dict Key-value mapping. Example: {"name": "Naveen"}

Most useful programs interact with information. Python provides input() for reading text from the user and print() for displaying information.

14 • Debugging

Common beginner errors

Errors are normal. Learning to read error messages is one of the most important programming skills.

SyntaxError

Python cannot understand the structure of your code.

print("Hello"

The closing parenthesis is missing.

NameError

You tried to use a name that Python does not know.

print(username)

If username was never defined, Python raises a NameError.

TypeError

An operation was attempted using incompatible types.

"Age: " + 37

Convert the number to text or use an f-string.

ValueError

A value has the right general type but cannot be converted as requested.

int("hello")

The text does not represent an integer.

IndentationError

Python found unexpected or inconsistent indentation.

if age >= 18: print("Adult")

The statement belonging to the if block needs indentation.

ZeroDivisionError

A program attempted to divide by zero.

result = 10 / 0

Check the divisor before performing the calculation.

Debugging habit: Read the last line of the traceback first to identify the error type, then inspect the line number and surrounding code.
