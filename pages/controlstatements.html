03 · Decisions

Boolean Expressions

A Boolean expression is an expression that evaluates to either True or False. Python uses these results to make decisions.

Comparison operators

== equal, != not equal, > greater, < smaller, >= greater/equal, <= smaller/equal.

Logical operators

and means both conditions are true; or means at least one is true; not reverses a Boolean result.

Example: Boolean expressions
age = 20
has_id = True

print(age >= 18)
print(age >= 18 and has_id)
print(age < 18 or has_id)
print(not has_id)
Expected output
True True True False
Line-by-line explanation

age = 20 stores an integer. has_id = True stores a Boolean. The first expression checks age. The second requires both conditions to be true. The third needs at least one true condition. The last reverses True to False.

Common mistake: = assigns a value; == compares two values.

Real-world example: A website might check whether a person is old enough and has completed identity verification.

Try it: Predict the result of 10 > 5 and 3 == 4. Answer: False, because both conditions must be true.

04 · Conditions

if and if-else Statements

What is an if statement?

An if statement runs a block only when its condition is true.

Syntax and example
temperature = 35

if temperature > 30:
    print("It is hot")
Expected output
It is hot

The colon : starts the block. The indented print() belongs to the condition.

if-else flowchart

When the condition is true, Python executes the if block. Otherwise, it executes the else block. Both paths then continue.

Example: pass or fail
marks = 42

if marks >= 40:
    print("Pass")
else:
    print("Fail")
Expected output
Pass
Line-by-line explanation

marks = 42 stores the score. marks >= 40 checks whether it is at least 40. The condition is true, so Python prints Pass and skips the else block.

Common mistake: Forgetting indentation or writing else with a condition. Plain else has no condition.

Exercise: Change the score to 25 and predict the output.

05 · Multiple decisions

if-elif-else

Use elif when you need to check several conditions in order. Python executes the first matching branch and skips the rest.

marks ≥ 90?
Yes →
Grade A
No ↓
marks ≥ 75?
Yes →
Grade B
No ↓
marks ≥ 50?
Yes →
Pass
No →
Needs Improvement
Sample mark: 82. The first condition is false; the second is true. Python prints Grade B and does not check later branches.
Example: calculate a grade
marks = 82

if marks >= 90:
    grade = "A"
elif marks >= 75:
    grade = "B"
elif marks >= 50:
    grade = "Pass"
else:
    grade = "Needs Improvement"

print("Grade:", grade)
Expected output
Grade: B
Line-by-line explanation

Python checks the highest threshold first. Since 82 is less than 90, it moves to the next condition. Because 82 is at least 75, it assigns "B". The remaining branches are skipped.

Common mistake: Check thresholds from highest to lowest. If you check marks >= 50 first, a score of 82 will match that branch and never reach the higher grades.

Exercise: Test scores 95, 70, and 35.

06 · Conditions inside conditions

Nested Conditions

A nested condition is an if statement inside another if statement. Use it when a second check should happen only after the first check succeeds.

Example: login access
username = "naveen"
password_correct = True

if username == "naveen":
    if password_correct:
        print("Login successful")
    else:
        print("Incorrect password")
else:
    print("Unknown user")
Expected output
Login successful
Line-by-line explanation

First, Python checks the username. Only if it matches does it evaluate password_correct. Both checks are true, so the login-success message appears.

Common mistake: Incorrect indentation changes which condition owns a statement. Avoid deeply nested logic when a simpler condition can do the job.

Exercise: Change password_correct to False. Then change the username.

07 · Repetition

for Loops and range()

A for loop repeats a block for each item in a sequence. range() generates a sequence of integers.

range(1, 6) starts at 1 and stops before 6. The stop value is excluded, so the values are 1, 2, 3, 4, and 5.

Example: print numbers
for number in range(1, 6):
    print(number)
Expected output
1 2 3 4 5

range() forms

Multiplication table

Example: table of 3
number = 3

for i in range(1, 6):
    print(number, "x", i, "=", number * i)
Expected output
3 x 1 = 3 3 x 2 = 6 3 x 3 = 9 3 x 4 = 12 3 x 5 = 15
Line-by-line explanation

number stores 3. The loop gives i the values 1 through 5. Each repetition calculates number * i and prints one line.

Real-world example: Process every student in a class or every order in a list.

Common mistake: Expecting range(1, 6) to include 6.

08 · Condition-controlled repetition

while Loops

A while loop repeats while its condition remains true. It is useful when the number of repetitions depends on a condition.

Initialize counter
↓
Evaluate condition
↓
Condition true?

↓

No
↓
Exit loop
↖ Return to condition after increment
Example: count to five
counter = 1

while counter <= 5:
    print(counter)
    counter += 1
Expected output
1 2 3 4 5
Line-by-line explanation

The counter starts at 1. Python checks whether it is at most 5, prints it, and adds 1. When the counter becomes 6, the condition is false and the loop ends.

Infinite loop warning: If the condition never becomes false, the loop may run forever. Make sure the loop body changes the condition or provide a deliberate exit such as break.

Common mistake: Forgetting counter += 1 in a counting loop.

Exercise: Modify the loop to print only 2, 4, 6, 8, and 10.

09 · Loop control

break and continue

break

Stops the current loop immediately.

Loop iteration
↓
break reached
↓
Exit loop
Example
for n in range(1, 6):
    if n == 3:
        break
    print(n)
Output
1 2

continue

Skips the remaining body for this iteration and moves to the next one.

Loop iteration
↓
continue reached
↓
Next iteration
Example
for n in range(1, 6):
    if n == 3:
        continue
    print(n)
Output
1 2 4 5

Line-by-line: Both examples visit numbers 1 to 5. With break, the loop ends when n is 3. With continue, only the print statement for 3 is skipped.

Real-world examples: Use break when a matching record is found. Use continue to skip invalid records and process the rest.

Common mistake: continue does not exit the loop. In a while loop, ensure any counter update needed for progress still happens.
10 · Text data

Strings

A string is a sequence of characters used to represent text. Python strings can use single quotes, double quotes, or triple quotes.

String examples
name = "Naveen"
message = 'Welcome to Python'
description = """Python is easy
to start learning."""

print(name)
print(message)
print(description)
Expected output
Naveen Welcome to Python Python is easy to start learning.
Line-by-line explanation

Each variable stores text. Triple-quoted strings can span multiple lines. print() displays the text without showing the quotation marks.

Important: Strings are immutable. You can create a new string from an existing one, but you cannot change an individual character in place.

Real-world example: Names, email addresses, messages, product codes, and postal addresses are commonly stored as strings.

Common mistake: Treating a number entered with input() as an integer without converting it.

Exercise: Create a variable containing your favourite programming language and print a sentence using it.

name = "  naveen kumar  "

12 · String positions

String Indexing and Slicing

Indexing accesses one character. Slicing extracts a section of a string. Python indexes start at zero, and negative indexes count backwards from the end.

word = "PYTHON"

Index 0P
Index 1Y
Index 2T
Index 3H
Index 4O
Index 5N

word[0] gives P · word[-1] gives N · word[1:4] gives YTH.

Indexing and slicing examples
word = "PYTHON"

print(word[0])
print(word[-1])
print(word[1:4])
print(word[:3])
print(word[3:])
print(word[::-1])
Expected output
P N YTH PYT HON NOHTYP
Line-by-line explanation

[0] selects the first character. [-1] selects the last. [1:4] includes indexes 1, 2, and 3 but excludes 4. An omitted start or end uses the beginning or end. [::-1] reverses the string.

Common mistake: A slice's ending index is excluded. Accessing an index outside the valid range directly, such as word[10], raises IndexError.

Exercise: Extract TH from PYTHON.

13 · Collections

Lists

A list stores multiple items in a particular order. Lists are mutable, which means you can update, add, and remove items. Duplicate values are allowed.

fruits = ["Apple", "Mango", "Orange"]

Index 0Apple
Index 1Mango
Index 2Orange

Access with an index, update with assignment, add with append(), and remove with remove() or pop().

List operations
fruits = ["Apple", "Mango", "Orange"]

print(fruits[1])

fruits[1] = "Banana"
fruits.append("Grapes")
fruits.remove("Apple")

print(fruits)
print(len(fruits))
Expected output
Mango ['Banana', 'Orange', 'Grapes'] 3
Line-by-line explanation

fruits[1] retrieves Mango. Assignment replaces it with Banana. append() adds Grapes at the end. remove() removes the first matching Apple. len() returns the number of items.

Common mistake: Using an index that does not exist or expecting indexes to begin at 1.

Real-world example: A shopping cart, a list of students, or a collection of product names.

Exercise: Create a list of three favourite foods, add one more, and print the first item.

14 · Fixed collections

Tuples

A tuple is an ordered collection that cannot be changed after creation. Tuples allow duplicate values and are useful for fixed groups of related values.

Tuple example
location = (25.32, 55.41)

print(location[0])
print(location[1])
print(len(location))
Expected output
25.32 55.41 2
Line-by-line explanation

The tuple stores two coordinates. Index zero retrieves the first value and index one retrieves the second. len() reports two items.

Single-item tuple: Use a trailing comma: one_item = (5,). Without the comma, (5) is simply an integer in parentheses.

Common mistake: Trying to assign to location[0]. Tuples do not support item assignment.

Exercise: Create a tuple containing your birth year, month, and day.

15 · Unique values

Sets

A set stores unique values. It is mutable, but it is not an indexed sequence and does not provide a guaranteed display order. Sets are useful for removing duplicates and checking membership.

Remove duplicate values
numbers = [1, 2, 2, 3, 3, 3]
unique_numbers = set(numbers)

print(unique_numbers)
print(2 in unique_numbers)

unique_numbers.add(4)
unique_numbers.discard(1)
print(sorted(unique_numbers))
Expected output
{1, 2, 3} (display order may vary) True [2, 3, 4]
Line-by-line explanation

set(numbers) removes duplicate values. The membership expression checks whether 2 exists. add() inserts 4, and discard() removes 1 if present. sorted() creates a sorted list for predictable output.

Common mistake: Sets do not support my_set[0]. An empty set is set(), not {}; empty curly braces create a dictionary.

Real-world example: Unique email addresses, distinct tags, or finding common interests between two groups.

Exercise: Find the unique values in [5, 5, 8, 9, 8].

16 · Key-value data

Dictionaries

A dictionary stores key-value pairs. Each key identifies a value. Dictionaries preserve insertion order in modern Python, are mutable, and require unique keys.

Student
name → Naveen
age → 37
city → Sharjah
skill → Python
Create and update a dictionary
student = {
    "name": "Naveen",
    "age": 37,
    "city": "Sharjah",
    "skill": "Python"
}

print(student["name"])
print(student.get("city"))

student["skill"] = "Java and Python"
student["country"] = "UAE"

print(student["skill"])
print(student["country"])
Expected output
Naveen Sharjah Java and Python UAE
Line-by-line explanation

The dictionary uses strings as keys and different types of values. Square brackets retrieve a value by key. get() can safely retrieve a missing key by returning None by default. Assignment updates an existing key or adds a new key.

Common mistake: Trying to access a dictionary using a numeric list-style index when the intended key is a string.

Real-world example: A student record, product details, or an API response.

Exercise: Create a dictionary for a book with title, author, and year.

17 · Compact collection creation

List Comprehensions

A list comprehension creates a list from an iterable in one concise expression. It can also include a condition to filter values.

Normal loop and comprehension
# Using a normal loop
squares = []
for n in range(1, 6):
    squares.append(n * n)

print(squares)

# Using a list comprehension
squares = [n * n for n in range(1, 6)]
print(squares)

# Include only even numbers
evens = [n for n in range(1, 11) if n % 2 == 0]
print(evens)
Expected output
[1, 4, 9, 16, 25] [1, 4, 9, 16, 25] [2, 4, 6, 8, 10]
Line-by-line explanation

The first loop appends each square to an initially empty list. The comprehension expresses the same transformation as [expression for item in iterable]. The last example adds if to keep only even values.

Common mistake: Making a comprehension so complicated that it becomes difficult to read. A normal loop is often clearer for several steps or nested logic.

Exercise: Create a list containing the cubes of numbers from 1 to 5.

18 · Collections inside collections

Nested Collections

A nested collection contains another collection. This is useful for representing tables, structured records, groups, and data returned by APIs.

List of dictionaries
students = [
    {"name": "Asha", "marks": 85},
    {"name": "Ravi", "marks": 92},
    {"name": "Mina", "marks": 78}
]

print(students[0]["name"])
print(students[1]["marks"])

for student in students:
    print(student["name"], student["marks"])
Expected output
Asha 92 Asha 85 Ravi 92 Mina 78
Line-by-line explanation

students is a list whose items are dictionaries. students[0] retrieves the first dictionary, and ["name"] retrieves that dictionary's name. The loop visits each student record.

Common mistake: Confusing a list index with a dictionary key. Use the index first, then the key in this example.

20 · Real code examples

Practical Examples

Study these complete examples. Each includes the expected output and an explanation of the important lines.

Example 1 — Positive, negative, or zero
number_check.py
number = -5

if number > 0:
    print("Positive")
elif number < 0:
    print("Negative")
else:
    print("Zero")
Expected output
Negative

Explanation: The first condition checks numbers above zero. The second checks numbers below zero. If neither condition is true, the number must be zero.

Common mistake: Leaving out the zero case.

Example 2 — Odd or even
odd_even.py
number = 7

if number % 2 == 0:
    print("Even")
else:
    print("Odd")
Expected output
Odd

Explanation: The modulo operator % returns the remainder. Even integers have remainder zero when divided by two.

Common mistake: Using / instead of % for this remainder check.

Example 3 — Grade calculation
grade.py
marks = 67

if not 0 <= marks <= 100:
    print("Invalid marks")
elif marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 50:
    print("Pass")
else:
    print("Needs Improvement")
Expected output
Pass

Explanation: The first condition validates the score. Python then checks grade thresholds from highest to lowest and prints the first matching result.

Common mistake: Forgetting to validate values outside the expected range.

Example 4 — Multiplication table
multiplication.py
number = 5

for i in range(1, 11):
    print(f"{number} x {i} = {number * i}")
Expected output
5 x 1 = 5 5 x 2 = 10 5 x 3 = 15 5 x 4 = 20 5 x 5 = 25 5 x 6 = 30 5 x 7 = 35 5 x 8 = 40 5 x 9 = 45 5 x 10 = 50

Explanation: range(1, 11) supplies 1 through 10. The f-string inserts variable values and the multiplication result into each line.

Common mistake: Using range(1, 10) when you want the table through 10.

Example 5 — Factorial
factorial.py
number = 5
factorial = 1

for i in range(1, number + 1):
    factorial *= i

print(factorial)
Expected output
120

Explanation: Factorial multiplies the positive integers from 1 through the given number. The accumulator starts at 1 because multiplying by 1 does not change the result. For this loop, 1 × 2 × 3 × 4 × 5 = 120.

Common mistake: Starting the accumulator at zero, which would keep the result at zero. The factorial of zero is also 1, so this initialised loop correctly produces 1 when the number is zero.

Example 6 — Find prime numbers
primes.py
for number in range(2, 21):
    is_prime = True

    for divisor in range(2, number):
        if number % divisor == 0:
            is_prime = False
            break

    if is_prime:
        print(number, end=" ")
Expected output
2 3 5 7 11 13 17 19

Explanation: The outer loop examines each number. The inner loop tries possible divisors. If any divisor leaves a remainder of zero, the number is not prime and the inner loop stops. Otherwise, the number is printed.

Common mistake: Treating 1 as a prime number. Prime numbers are integers greater than 1 with exactly two positive divisors.

Example 7 — Iterate through a string
characters.py
word = "CODE"

for character in word:
    print(character)
Expected output
C O D E

Explanation: A string is iterable. Each loop iteration assigns the next character to character.

Common mistake: Trying to change the string by assigning to a character index. Strings are immutable.

Example 8 — Search a list
search_list.py
names = ["Asha", "Ravi", "Mina"]
target = "Ravi"

found = False

for name in names:
    if name == target:
        found = True
        break

if found:
    print("Found")
else:
    print("Not found")
Expected output
Found

Explanation: The loop compares each name with the target. A match changes found to True and stops the loop.

Common mistake: Printing “Not found” inside the loop after the first non-matching item.

Example 9 — Remove duplicates with a set
unique_values.py
values = [3, 1, 3, 2, 1, 4]
unique_values = sorted(set(values))

print(unique_values)
Expected output
[1, 2, 3, 4]

Explanation: set() removes duplicate values. sorted() returns a list in ascending order, making the output predictable.

Common mistake: Assuming a set retains the original list order.

Example 10 — Create a dictionary
product.py
product = {
    "name": "Keyboard",
    "price": 75,
    "in_stock": True
}

print(product["name"])
print(product["price"])
print(product["in_stock"])
Expected output
Keyboard 75 True

Explanation: The dictionary groups a product's name, price, and availability. Each value is retrieved through its key.

Common mistake: Requesting a key that does not exist using square brackets, which raises KeyError.

Example 11 — Count word frequency
word_frequency.py
text = "python is easy and python is useful"
words = text.split()
frequency = {}

for word in words:
    frequency[word] = frequency.get(word, 0) + 1

print(frequency["python"])
print(frequency["is"])
Expected output
2 2

Explanation: split() creates a list of words. get(word, 0) returns the current count or zero if the word has not appeared. The count is incremented for each word.

Common mistake: Ignoring punctuation or capitalisation when analysing real text. This simple example assumes lowercase words without punctuation.

Example 12 — List comprehension
filter_even.py
numbers = range(1, 11)
even_squares = [n * n for n in numbers if n % 2 == 0]

print(even_squares)
Expected output
[4, 16, 36, 64, 100]

Explanation: The expression squares each selected number. The if clause keeps only even numbers before adding their squares to the list.

Common mistake: Putting the filter in the wrong place or forgetting that the comprehension returns a new list.
